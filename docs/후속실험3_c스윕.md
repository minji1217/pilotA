# 갈래 ⑤ — 면적 계수 c 스윕 (후속실험 3 이후)

## 왜 했나

면적 항 `z = a·log p̄ + b + c·(log k − m)` 에서 **c = 1은 "격자 칸끼리 독립"이라는
가정에서 나온 유도값**이다. 그런데 실측 예측 편향이 LS +0.436 / LQ +0.256으로
둘 다 크게 과대추정이었고, c = 0.5로 내리면 LS −0.097 / LQ −0.103으로 부호가 뒤집혔다.
즉 두 hazard 모두 최적 c가 0.5와 1 사이에 있다. 그 사이를 실제로 훑었다.

## 어떻게 돌렸나

| 항목 | 값 |
|---|---|
| 브랜치 | `followup3-area-sweep` (`followup3-area-avg-fixed`에서 분기) |
| 모드 | `AreaPrior(mode="grid", c_ls=…, c_lq=…)` — **a=1, b=0 고정이라 prior에서 학습하는 값이 0개** |
| 거친 격자 | c_LS × c_LQ ∈ {0.3 … 1.0} 8×8 = **64점** |
| 미세 격자 | c_LS × c_LQ ∈ {0.58 … 0.68} 0.02 간격 6×6 = **36점** |
| 공통 | lam_gamma = 10 · 3000 epoch · Adam lr 0.02 · seed 0 |
| 평가 | LS 418행(양성률 25.1%) / LQ 229행(47.6%) · 이벤트별 AUC를 행 수로 가중평균 |

**검증**: 격자점 (1.0, 1.0)이 조건 A fixed와 완전히 일치한다 —
`ls_prior 0.885006 / ls_post 0.860661 / mse_ls 0.368261 / bias_ls 0.435663 / NLL 6370.144886`.
마지막 NLL은 후배 교차검증 폴더의 A fixed 기록값과도 같다.

## 결과 1 — 두 hazard의 c는 서로 간섭하지 않는다

`c_LQ`를 0.3에서 1.0까지 바꿔도 LS 지표가 움직이는 폭:

| 지표 | 같은 c_LS 안에서 최대−최소 |
|---|---:|
| LS 편향 | 0.0030 |
| LS MSE | 0.0060 |
| LS posterior AUC | 0.0087 |

반대 방향도 같다(LQ 편향 0.0031 / MSE 0.0067 / AUC 0.0131).
c를 바꾸면 그 hazard의 편향이 0.6 넘게 움직이는 것과 비교하면 사실상 0이다.

**`c_LS`와 `c_LQ`를 따로 골라도 된다.** 2차원 격자를 훑을 필요가 없었다는 뜻이기도 하다.

## 결과 2 — 최적 c는 두 hazard 모두 0.62 근처다

다른 hazard의 c에 대해 평균한 값이다.

|---|---:|---:|---:|---:|---:|---:|

| 0.4 | −0.1562 | 0.1656 | 0.8539 | −0.1940 | 0.2282 | 0.7741 |
| 0.5 | −0.0964 | 0.1448 | 0.8401 | −0.1042 | 0.1927 | 0.7887 |
| **0.6** | **−0.0216** | **0.1336** | 0.8344 | **−0.0147** | **0.1776** | 0.7876 |
| 0.7 | +0.0773 | 0.1457 | 0.8348 | +0.0673 | 0.1806 | 0.7919 |
| 0.8 | +0.1982 | 0.1931 | 0.8370 | +0.1396 | 0.1962 | 0.7866 |
| 0.9 | +0.3248 | 0.2735 | 0.8485 | +0.2023 | 0.2203 | 0.7842 |
| 1.0 | +0.4362 | 0.3684 | 0.8629 | +0.2566 | 0.2499 | 0.7800 |

미세 격자(0.58~0.68)로 다시 재면:

- **편향이 0을 지나는 곳: c_LS ≈ 0.624, c_LQ ≈ 0.616**
- MSE 최소: c_LS = 0.60 (0.1335), c_LQ = 0.62 (0.1774). 구간 안에서 거의 평평하다.

두 hazard가 거의 같은 값을 원한다. 0.58~0.68에서 MSE가 평평하므로 **0.62 하나로 묶어도 손해가 없다.**

## 결과 3 — 새 조건 K (c_LS = c_LQ = 0.62)

| 조건 | LS AUC | LS MSE | LS 편향 | LQ AUC | LQ MSE | LQ 편향 |
|---|---:|---:|---:|---:|---:|---:|
| **K c=0.62** | 0.8352 | **0.1335** ✅ | **−0.004** | 0.7848 | **0.1774** ✅ | **+0.003** |
| C bounded | **0.8812** | 0.1148 ✅ | +0.009 | 0.7813 | 0.2507 ✗ | −0.214 |
| E a1-c05 | 0.8435 | 0.1429 ✅ | −0.097 | 0.7914 | 0.1932 ✅ | −0.103 |
| J b-only | 0.8466 | 0.1469 ✅ | +0.083 | **0.8100** | 0.2217 ✅ | −0.192 |
| A fixed | 0.8607 | 0.3683 ✗ | +0.436 | 0.7812 | 0.2497 ✗ | +0.256 |

✅ = MSE 기저확률(LS 0.1881 / LQ 0.2494) 아래. K는 학습 prior 파라미터가 0개이고 NLL 6322.2다.

**두 hazard의 MSE가 동시에 기저확률을 밑돌면서 편향도 둘 다 0에 붙는 조건은 K 하나뿐이다.**
기존 15개 조건에는 없었다 — C는 LQ MSE가 기저를 0.0013 차이로 못 넘고, E·J는 편향이 0.10~0.19 남는다.

## 결과 4 — 그래도 LS에서 피해 데이터가 보태는 것은 없다

LS posterior AUC는 **c = 0.6 근처에서 오히려 가장 낮다**(0.8344). 자기 prior는
전 구간 0.885~0.897이라 **보탠양이 c를 어떻게 골라도 음수**다(−0.022 ~ −0.063).

눈금이 맞는 자리(c ≈ 0.62)와 순위가 좋은 자리(c = 1.0, AUC 0.8629)가 서로 다르다.
후속실험 3의 가장 큰 발견 — "지금 모델에서 피해 데이터가 LS 순위에 보태는 것이 없다" —
는 c를 최적화해도 바뀌지 않는다. **c는 눈금 문제를 고치지 순위 문제를 고치지 못한다.**

LQ는 반대로 전 구간에서 보탠양이 양수다(+0.010 ~ +0.034).
